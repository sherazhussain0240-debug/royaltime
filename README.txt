ROYAL TIME WEB APP

How to use:
1. Extract the ZIP file.
2. Open the royal_time_webapp folder.
3. Double-click index.html to open the app in a browser.

Includes:
- Home dashboard
- Watch collection and product search
- Demo shopping cart
- Order request form
- About Royal Time
- Store management demo for adding watches

Important:
This is a front-end demo. It does not include a database, customer accounts,
online payment processing, or live order delivery. Products added in the demo
are not permanently saved. A backend and payment/order integrations are needed
before using it as a live business store.
